# Beyond the Pail: campaign media

Public media files for the *Beyond the Pail* (Andrew M. Davidson) social campaign. The scheduling tool fetches the images and videos from here.

- `dayN_*`: posts for campaign day N (stories 1080×1920, feed and carousel 1080×1350, reels 1080×1920)
- `Beyond_the_Pail_trailer_16x9.mp4` and `youtube_thumbnail_1280x720.jpg`: the YouTube trailer and its thumbnail
- `Beyond_the_Pail_Book_Club_Guide.pdf`: free book-club discussion guide
